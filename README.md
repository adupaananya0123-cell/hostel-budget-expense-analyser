2. Objective

The objective of this project is to calculate and analyze the expenses of hostel students. It helps students understand their total spending, remaining budget and highest expense.

3. Technologies Used

- Python
- NumPy
- Pandas

4. Dataset Description

The project uses sample data containing five expense categories: food, travel, books, snacks and shopping. Each category has a corresponding expense amount. The monthly budget is Rs. 5,000.

5. Implementation

1. Declare the monthly budget.
2. Store expense names and amounts in lists.
3. Create a dictionary to organize the data.
4. Use Pandas to create a DataFrame.
5. Use NumPy to calculate total, highest and average expenses.
6. Use an if-else condition to check the budget status.
7. Display the results.

6. Key Features

- Displays expense details.
- Calculates total expenses.
- Calculates remaining money.
- Finds the highest expense.
- Calculates average expenses.
- Checks whether spending is within the budget.

7. Output / Results

- Monthly Budget: Rs. 5,000
- Total Expenses: Rs. 3,700
- Remaining Money: Rs. 1,300
- Highest Expense: Rs. 1,500
- Average Expense: Rs. 740
- Budget Status: Budget is Within Limit

8. Final Outcome

The project successfully calculates hostel expenses and displays the remaining budget. It helps students understand their spending habits and manage their money better.

9. Challenges and Learning

I learned how to use Python variables, lists, dictionaries and conditional statements. I also learned how to create a Pandas DataFrame and perform basic calculations using NumPy.
